# Mijn Linux Website – Opdracht 22

Dit is mijn website voor **opdracht 22** van Linux Client.

## Over het project

Ik heb een eenvoudige website gemaakt met HTML en CSS in Visual Studio Code. De website heeft een navigatiebalk, een welkomstgedeelte en informatie over de opdracht.

Voor deze versie gebruik ik **GitHub Pages** in plaats van de FTP-server WEB03 uit de opdracht.

## Bestanden

- `index.html` – de inhoud van de website.
- `style.css` – de opmaak en kleuren van de website.
- `README.md` – informatie over het project.

## Website openen

Open `index.html` in een browser om de website lokaal te bekijken.

## Publiceren met GitHub Pages

1. Maak op GitHub een openbare repository aan, bijvoorbeeld `linux-website`.
2. Upload `index.html`, `style.css` en `README.md` naar de hoofdmap van de repository.
3. Ga naar **Settings → Pages**.
4. Kies bij **Build and deployment** voor **Deploy from a branch**.
5. Selecteer de branch `main` en de map `/(root)` en klik op **Save**.
6. Wacht tot GitHub Pages je website heeft gepubliceerd. De link verschijnt bij **Settings → Pages**.

De website is dan meestal bereikbaar op `https://GEBRUIKERSNAAM.github.io/linux-website/`.
